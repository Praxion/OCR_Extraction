BRData System Overview
Clements Marketplace – Portsmouth & Bristol
BRData HOST

What: Where you enter NEW items, make price changes, create Links, and where AD sales run through.

Why: HOST connects Portsmouth & Bristol together — keeps both stores in sync on items and pricing.

BRData STORE

What: Where you enter Manager Instores, take off instore sales, and make signs/tags.

Why: STORE is at "Store Level" — instore sales only reflect in the Portsmouth store.

Store #4 Bristol  |  Store #3 Portsmouth

🔑 Key Concepts

• Batch # – every action is tied to a numbered batch
• UPC – Short UPCs: drop first digit. Long/European UPCs: drop last digit. When in doubt, always scan it.
• LINK – groups of UPCs with the same pricing
• Instore – store-level sale using the Shoppers Card
• WSL – "While Supplies Last"

HOST – Adding New Items
Use BRData HOST to enter new items. Changes push to both stores.
Step-by-step: Entering a New Item Manually
1

Open BRData HOST → Product Master

Launch BRData HOST and navigate to BRData Host → Product Master.

2

Enter Batch # and Description, then click OK

Type in your batch number, add a description, then click OK. The system will populate a new screen.

3

Type the UPC in the "Search For" box → ENTER

Enter the UPC code and press ENTER on your keyboard.

UPC Tips: Short UPCs – drop the first small digit. Long/European UPCs – drop the last digit. When in doubt, always scan it when done.
4

Confirm "Add the Item" prompt

A box will appear asking if you want to add the item. Click ENTER again or click Add the Item.

5

Fill in the required fields

Dep/Sub – Department
Cat/Sub – Subcategory
Size(Alpha) – Size
MLink – Link #
Description
POS Desc
Note: The image provided of BR DATA is of the store level not the HOST.
6

Click "Save"

Once all information is filled out, click Save.

7

Enter the retail price → Save

A new screen will appear — enter the retail price on the left-hand side only where the store numbers appear (000003 and 000004). Once finished press Save.

Only enter retail in rows where the store numbers are shown (000003 Portsmouth, 000004 Bristol). If they are in 00000A it will apply to all stores available.
Block Copy – Using a "Friend" Item

If you have a similar existing item, you can COPY/BLOCKCOPY it to speed up entry. Most fields will carry over; you'll only need to update size and UPC.

1

Type the "friend" UPC in the "Search For" box → ENTER

Find the similar item you want to copy from.

2

Click the double block icon

Click the Block Copy icon in the toolbar (double-block icon).

3

Enter the new UPC in the "UPC Code" box

All fields will copy from the "friend." The only field that may change is SIZE (Dep/Sub, Cat/Sub, Size(Alpha), Description, POS Description).

4

Watch for Instores & sign items

Keep an eye out for "Instore" and "sale" items — they may need a sign printed.
Note: The image used for this example is based on Store not Host.
5

Follow steps 6 & 7 for adding a retail price

Complete the same Save and retail entry steps as manual entry (steps 6 & 7 above).

Exporting a New Item Batch FROM BRData HOST
1

BRData HOST → Export Batches → Selected Batches → Accept

Navigate through the Export Batches menu and select the batch.

2

Check off your Batch # → Accept again → Export Batches

Check (√) your batch number, accept again, then click Export Batches.

3

Verify both stores are selected

Make sure the batch sends to BOTH stores. When export is done, press OK.

Both stores should show: 000003 Portsmouth & 000004 Bristol.
⚠️ If the Batch Doesn't Export (Blank Status Box)
1

Click "Store Selection"

In the Export screen, click the Store Selection tab.

2

Make sure ALL stores are checked in the "Selected Stores" box

Check that 000003 Portsmouth and 000004 Bristol are both checked/selected.

If the status box is blank after export, the batch did NOT go through — re-export after verifying store selection.
3

Export batch like normal once stores are confirmed

STORE – Manager Instores
Use BRData STORE for manager instore sales. Instore = Shoppers Card sale.
Turning a Manager Instore ON
1

Open BRData Store → Product Master

Launch BRData STORE and click BRData → Product Master.

2

Check both top boxes → click "Next" for next batch #

Check both checkboxes at the top. Click Next to get the next available batch number. Date will always be current day.

3

Fill in the batch settings

Description → "Instore On [vendor/dept/manager]" e.g. "Instore On Kraft"
Batch Mode/Date Default → Frequent Shopper
Price End Date → Enable Calendar Object → type 12/01/2029 (WSL date)
Priority → click [...] icon → select "Manager" priority 50
Batch Mode = Frequent Shopper — This applies the sale every time the shopper card is used at the registers.
Price End Date 12/01/2029 — This is our "While Supplies Last" date.
4

Click OK → Confirm YES

A confirmation box will pop up — click YES. This tells you the sale will happen immediately.

5

Enter UPC in "Search For" → ENTER

6

Enter sale retail in the "Future Prices" box → Save

Verify dates, modes, and prices before saving.
7

If item is on a Link

All items in the link will pop up. Deselect if only putting that one item on sale, or Select All if the whole link gets the same sale.

Turning a Manager Instore OFF
1

Open BRData Store → Product Master

Same entry path as Instore ON.

2

Check both boxes → Next → fill in Description

Description = "Instore Off [vendor/dept/manager]" — e.g., "Instore Off Kraft". Click OK.

3

Enter UPC → ENTER → click "Future Prices" box

4

A new box will pop up showing all SALE retails

Click the SALE you want to take OFF SALE so it highlights blue, then click DELETE.

Look out for other active sales that may overlap: AD, WAVE, SAVE. Only delete the instore you intend to remove.
5

Confirm deletion → YES

A box will confirm you want to take the item off sale. Click YES.

6

Back on Product Master → click SAVE

If you have more items to take off sale, go through the process again. Once done, close out of Product Master.

Tag Batch – Quick Way to Add UPCs for Tag Printing

Tag Batch is a quick way to add UPCs to a batch to print tags/signs easily. It does NOT update item, price, or cost information — it only updates the batch.

1

Open BRData → Product Master

Uncheck "Direct Item Maintenance" and click Next for next available batch #. Date will always be current day.

2

Fill in Description and Batch Mode

Description → anything easy to remember e.g. "TAGS FOR PEPSI"
Batch Mode/Date Default → Tag Batch
3

Click OK → then OK again on the notice

A notice will appear reminding you this DOES NOT update item/price/cost info. Click OK.

4

Type UPC in "Search For" → ENTER

A box will pop up asking if you want to add the UPC to the batch. Click YES.

5

If item is on a Link — linked items will pop up

Keep selected to add all linked items, or unselect to add only that one item. Click UPDATE when finished.

6

Add remaining UPCs → Close Product Master → Print tags/signs

Follow the "Tags & Signs" tab to print once all UPCs are in the batch.

Printing Tags & Sale Signs
Use BRData STORE to print shelf tags and sale signs using Designer Labels (DRL).
Printing from a Batch
1

Open BRData Store → Batch File → OK

Navigate to BRData Store → Batch File and click OK.

2

Click the batch you want → "Export Labels"

Click the desired batch so it highlights blue, then click Export Labels.

3

Confirm YES → then click "Print"

A new box will pop up — click YES, then in the next box click Print.

4

Designer Labels (DRL) opens with batch items

This program will open all items from the batch you selected. Verify you opened the correct batch.

5

Change descriptions if needed (sale signs only)

Change descriptions ONLY if printing sale signs. For shelf tags, you don't need to change descriptions.

Check items to select them for printing. You can select all items or check/uncheck individually.
6

Click "Assign Template" → double-click the template you want

A pop-up will show all available templates. See the Template Reference section below.

7

Print using QuickQ or "Advanced Printing"

Use the quick print icon (QuickQ) for normal printing, or Advanced Printing if you want to print on a specific row.

Printing Signs Using a Date Range
1

BRData Store → Export Item File and Labels

Navigate through the QUERY TAB. Enter a Process Date (batch starting date).

2

BY Batch: Enter From & To Dates and Batch # → OK

Your batch should pop up — verify, select to highlight, and click OK. The Batch Items Selection Box will pop up — click ACCEPT.

3

EXPORT TAB settings

√ Export Label File
√ Print After (auto pop-up)
√ Movement Only

Click Process → SALES MOVEMENT box pops up → enter date range you want → ACCEPT.

4

Let it process → OK → PRINT

Once the Completed Export of Label File BOX appears, click OK, then PRINT.

Price Change – Current Day
Making a price change batch in BRData HOST for the same day it takes effect.
1

Open BRData HOST → Product Master

2

Create the batch

Batch Number → enter batch #
Batch/Activation Date → CURRENT DATE (auto-filled)
Description → PRICE CHANGES
Batch Mode → Future Retail Price

Then click OK.

3

Enter UPC in "Search For" → ENTER

4

Enter new retail on RIGHT SIDE for both stores → SAVE

A new window will pop up. Enter the new retail on the right side only for the two stores, then press SAVE.

If the item is attached to a Link, click UPDATE ALL.
5

The change saves when you see it populate on the right side

You'll see the new retail, date of batch, and batch number appear on the right side.

6

Repeat for each UPC → close Product Master

7

BRData Host → View-Apply Future Prices

A new window opens. Click SELECT, then select your batch and click OK.

8

Confirm YES → OK → Apply Prices

A confirmation pops up asking you to confirm. Click YES, then click OK. The last screen shows again — use SHIFT + down arrow to highlight all items on the batch blue, then click APPLY PRICES.

9

Confirm YES again → EXIT → Export batch to stores

EXIT the page and export the batch to the stores as normal.
Price Change – Future Dates
Making a price change batch in BRData HOST for a future date. It will auto-export on that day.
1

Have your price changes (sent by Brian) ready

Make sure you have the price change list in front of you before starting.

2

Open BRData HOST → Product Master

3

Create the batch

Batch Number → enter batch #
Batch/Activation Date → enter the date you are making the changes for
Description → PRICE CHANGES
Batch Mode → Future Retail Price

Click OK.

4

Enter UPC in "Search For" → ENTER

5

Enter new retail on right side for both stores → SAVE

Same as current-day price change — enter retail on the right side only for the two stores.

If attached to a Link, click UPDATE ALL.
6

Confirm save by seeing it populate on the right side

7

Repeat for each UPC → close Product Master

Since you made a batch with a future date it will automatically export that day. Send an email to all stores with the date of the price change batch and batch number so they know when to change tags.
